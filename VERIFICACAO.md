# Verificação

A suíte completa permanece obrigatória antes de integrar/publicar. Use `npm run verify` para obter resumo e log completo. O manifesto de preparação relaciona a verificação à fonte exata; alterações posteriores invalidam essa confirmação.

Mudanças visuais exigem revisão no navegador. Manutenção apenas de documentação/ferramentas deve demonstrar que a árvore `dist/` não mudou.

[Registros integrais até 0.8.2](docs/history/VERIFICACAO-ate-0.8.2.md).
